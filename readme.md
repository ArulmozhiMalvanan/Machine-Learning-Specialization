# Machine Learning Foundations: A Case Study Approach

A hands-on learning repository documenting my journey through the **Machine Learning Foundations: A Case Study Approach** course offered by the University of Washington on Coursera.

This repository contains my learning notes, Python implementations, Jupyter notebooks, experiments, and practical exercises covering fundamental Machine Learning concepts through real-world case studies.

|---|---|

## Learning Objectives

Through this course, I aim to:

- Understand fundamental Machine Learning concepts.
- Differentiate between regression, classification, and clustering.
- Understand feature engineering and data representation.
- Train and evaluate Machine Learning models.
- Explore recommendation systems and document retrieval.
- Understand the fundamentals of Deep Learning.
- Build practical Machine Learning applications using Python.
- Understand the basics of deploying Machine Learning models.

## Course Curriculum

### Module 1: Welcome to Machine Learning

- Introduction to Machine Learning.
- Applications of Machine Learning.
- Python programming fundamentals.
- Introduction to Jupyter Notebook.
- Working with datasets and data transformation.

### Module 2: Regression - Predicting House Prices

- Introduction to Regression.
- Linear Regression.
- Feature selection.
- Training and testing datasets.
- Overfitting.
- Model evaluation.
- Root Mean Squared Error (RMSE).

**Practical Case Study:** House Price Prediction.

### Module 3: Classification - Analyzing Sentiment

- Introduction to Classification.
- Linear classifiers.
- Decision boundaries.
- Training and evaluating classifiers.
- Confusion Matrix.
- False Positives and False Negatives.
- ROC Curve.
- Classification Accuracy.

**Practical Case Study:** Product Review Sentiment Analysis.

### Module 4: Clustering and Similarity - Retrieving Documents

- Introduction to Clustering.
- Unsupervised Learning.
- K-Means Clustering.
- Document Similarity.
- Word Count Representation.
- TF-IDF.
- Nearest Neighbors.

**Practical Case Study:** Wikipedia Document Retrieval.

### Module 5: Recommending Products

- Introduction to Recommendation Systems.
- Collaborative Filtering.
- User-Item Interactions.
- Matrix Factorization.
- Popularity-Based Recommendations.
- Personalized Recommendations.
- Precision and Recall.

**Practical Case Study:** Song Recommendation System.

### Module 6: Deep Learning - Searching for Images

- Introduction to Deep Learning.
- Neural Networks.
- Image Classification.
- Deep Features.
- Transfer Learning.
- Image Similarity.
- Nearest Neighbors for Image Retrieval.

**Practical Case Study:** Image Classification and Image Retrieval.

### Module 7: Closing Remarks

- Deploying Machine Learning Services.
- Understanding the Machine Learning Pipeline.
- Challenges in Machine Learning.
- Future of Intelligent Applications.
